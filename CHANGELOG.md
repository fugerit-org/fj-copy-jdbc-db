## [1.0.0] - 2026-05-23

### Added
- Dynamic JDBC database table copying utility (`CopyJDBC`) with metadata-driven query execution, robust LOB/Null mapping, and high-performance batch insert support.
- `CopyJDBCTool` utility class to perform copy operations directly driven by connection and query `Properties`.
